## Задания 6.3 и 6.4

Функция варианта 9: **f(x) = √x + 1** (единица находится вне корня).

- Исходные узлы: `xᵢ = 1 + 0,1i`, `i = 0…10`, значения `yᵢ = √xᵢ + 1`.
- Новая сетка: `xⱼ = 1 + 0,05j`, `j = 0…20`.
- Метод: полином Ньютона на разделённых разностях; на равномерной сетке он эквивалентен записи с конечными разностями.
- Степень `m` задаётся пользователем. По умолчанию `m = 3`, для каждой точки выбираются `m + 1` ближайших узлов. При одинаковых расстояниях выбирается левый узел. При `m = 10` используются все 11 узлов.
- Производные вычисляются аналитическим дифференцированием полинома в схеме Горнера. Точные значения: `f′(x) = 1/(2√x)`, `f″(x) = −1/(4x√x)`.

Вкладка **6.3** показывает график функции и полинома, исходные узлы, таблицу новой сетки и абсолютные ошибки. Вкладка **6.4** показывает обе производные в таблице, выбранную производную на графике и её погрешность. В таблице приведены индексы узлов каждого локального полинома. В местах смены окна локальные полиномы и их производные могут иметь скачки.

Максимальные ошибки вычисляются на **новой сетке**, а не на всём отрезке. Для исходных настроек (`m = 3`):

| Величина | Максимальная абсолютная ошибка |
| --- | ---: |
| f | ≈ 2,4158085 · 10⁻⁶ |
| f′ | ≈ 1,5986305 · 10⁻⁴ |
| f″ | ≈ 6,0794091 · 10⁻³ |

В поле **«Функция f(x)»** можно ввести своё выражение, например `sin(x)`, `x^2`, `exp(-x^2)` или `ln(x)`. При включённом флажке **«Вычислять y таблицы по формуле»** значения исходной таблицы пересчитываются на Go при нажатии «Рассчитать». Для сравнения производные введённой функции вычисляются автоматическим дифференцированием выражения, а производные полинома — схемой Горнера.

В раскрывающемся блоке можно редактировать исходную таблицу и вводить произвольную новую сетку. Формат таблицы: `x; y`, по паре на строку; десятичный разделитель — точка. Для таблицы с неизвестной функцией отключите вычисление y по формуле и аналитическое сравнение: точные значения и погрешности будут обозначены «—». Экстраполяция отключена. Допускаются 2–201 исходный узел, 1–2001 новый узел, степень от 1 до `min(20, число узлов − 1)`.

В обоих разделах поддерживаются `x`, константы `pi`, `e`, операции `+`, `-`, `*`, `/`, `^`, скобки и функции `sqrt`, `sin`, `cos`, `tan`, `exp`, `ln`, `log`, `abs`. `ln` и `log` — натуральный логарифм, углы задаются в радианах. Умножение пишется явно: `2*x`. Степени связываются справа: `x^2^3 = x^(2^3)`, а `-x^2 = -(x^2)`. Формула ограничена 256 символами. Для сравнения первой и второй производных выбирайте отрезок, на котором они существуют. «Восстановить вариант 9» возвращает исходную формулу и параметры.

Теория: `docs/Вычислительные методы - пособие.pdf`, §§ 7.7, 7.9 и глава 8. Номера 6.3–6.5 относятся к **заданиям КР/ЛР**, а не к главам учебного пособия.

## Задание 6.5

```text
       0,75
I = ∫       dx / (√(1 − x²) · √(1 + x²))
      −0,75
```

Подынтегральная функция эквивалентна `1/√(1 − x⁴)`.

1. Выберите **Симпсона**, **трапеции** или **средние прямоугольники**, задайте начальное число интервалов `n₀ = 8` и относительную точность. Приложение последовательно удваивает число интервалов. Для Симпсона `n₀` должно быть чётным.
2. Выберите **Гаусса — Лежандра**, порядок **8**. Первый расчёт — обычная восьмиузловая формула на всём отрезке. Затем используется составная формула с удвоением числа панелей и сохранением порядка. Стандартные узлы и веса показаны в отдельной таблице.

При первом открытии вкладки 6.5 расчёт запускается автоматически, и график заполняется без нажатия кнопки. Поле **«Подынтегральная функция f(x)»** позволяет заменить формулу варианта своей. Для функции варианта 9 границы ограничены `−0,99 ≤ a < b ≤ 0,99`; для своей функции допустимы конечные границы от −1 000 000 до 1 000 000 с длиной отрезка не менее `10⁻⁹`. Функция должна быть непрерывной и конечной на всём отрезке.

По умолчанию относительная точность `ε = 10⁻⁶`, задаётся **долей**, а не процентами. В поле можно вводить `10⁻⁶`, `10^-6` или `0,000001`. Допустимы `ε` от `10⁻¹²` до `0,1`, `n₀` от 1 до 4096, порядок Гаусса от 2 до 16. Числа в таблицах, карточках, подписях графиков и подсказках выводятся со степенями, например `2,4 × 10⁻⁶` (с десятичной точкой в интерфейсе), вместо записи с буквой e.

Для формул Ньютона — Котеса используется оценка Рунге:

```text
R = |I₂ₙ − Iₙ| / (2ᵖ − 1)
p = 4 для Симпсона; p = 2 для трапеций и средних прямоугольников
```

Для Гаусса используется `R = |I₂ₙ − Iₙ|`, без потенциально преждевременного деления на `2²ᵐ − 1`. Это численная оценка, а не гарантированная верхняя граница. Критерий остановки: `R / |I₂ₙ| ≤ ε` **и** фактическое относительное отклонение от независимого эталона не превышает `ε`. Возвращается непосредственно уточнённая квадратура, без добавления поправки Ричардсона.

Эталон вычисляется отдельным сходящимся степенным рядом:

```text
F(x) = Σₖ₌₀∞ C(2k,k) · x⁴ᵏ⁺¹ / [4ᵏ(4k+1)]
Iэт = F(b) − F(a)
```

Для варианта 9: **I ≈ 1,5551759744797**. Значение эталона является численным приближением с точностью `float64`. Максимум — 1 048 576 интервалов; при недостижении точности приложение явно сообщает об этом.

Для своей функции независимый эталон неизвестен: приложение показывает оценку метода и не выдаёт её за фактическую погрешность. Остановка выполняется по этой оценке, предел — 65 536 интервалов. При `|I₂ₙ| < 10⁻¹²` используется абсолютный критерий `R ≤ ε`, о чём выводится сообщение. Разрывы и быстро осциллирующие функции могут сделать оценку по последовательным приближениям ненадёжной.

Интерфейс показывает площадь под графиком, сходимость, все уточнения сетки, оценочную и фактическую погрешности. Теория: глава 9 учебного пособия (квадратуры Ньютона — Котеса, Гаусса, правило Рунге).
